# Tost Makinesinin Eşit Kızartma Anayasası

Bu depo, evrenin en küçük ama en kanlı adaletsizliğini düzenler: **bir dilim kömür, öteki hâlâ sabah ekmeği.**

Bilimsel değildir. Anayasaldır. Patates yoktur. Peynir vardır.

## Bu yazılım ne yapar?

İki dilimin kızarma yüzdesini ölçer, farkı hesaplar ve **bağlayıcı** bir karar metni basar. İtiraz yoktur çünkü tost soğur.

```bash
python3 anayasa.py
python3 anayasa.py 55 57
python3 anayasa.py 12 91
```

İlk komut evrenin rastgele zalimliğini simüle eder. Diğerleri senin vicdanındır.

## Anayasa Özeti

1. Sol plaka ile sağ plaka eşittir. Bu bir temenni değil, fiş zorunluluğudur.
2. Yüzde farkı 8'in altındaysa sandviç meşrudur.
3. Yüzde farkı 20'nin üstündeyse Tost Meclisi olağanüstü toplanır (toplanmaz, sen yersin).
4. Kapağı merak için açmak, süreci bozar. Merak sucuktur, sucuk da yanar.
